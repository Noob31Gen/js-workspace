# CORS Fetch Helper - Browser Extension

This lightweight Chrome/Edge Extension allows the **JS Workspace** web application to fetch data from any web link or API without encountering CORS (Cross-Origin Resource Sharing) blockages.

---

## 🛠️ Installation Instructions

1. Open **Google Chrome**, **Brave**, or **Microsoft Edge**.
2. Open the extensions page:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. Toggle **Developer mode** (top-right corner).
4. Click **Load unpacked**.
5. Select this `extension/` folder directory.
6. The extension is now active! Reload your JS Workspace web app (`http://localhost:3000`), and the **CORS Helper Connected** status badge will turn green.
